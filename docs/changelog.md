# Muzik Desktop changelog

Release notes for Muzik Desktop. Muzik is built by Ignatius (lead developer)
together with the Pipo Team contributors and is released under GPL-3.0.

---v7.9.5
# Support and updates, everywhere
- The M logo is hard-coded across the window, taskbar (including pinned buttons), Alt-Tab and the system tray
- Update messages arrive as system notifications; updates install in the background or inside the app, depending on where you are
- A hot coffee cup beside the history icon opens Buy Me a Soda, with gentle in-app support prompts and a thank-you pop-up after a contribution
- Removed song-artwork color theming for a cleaner, more consistent look
- README install guidance now matches the installer (Desktop and Start Menu shortcuts)

---v7.9.4
# A smoother M
- The M logo orbit loading indicator replaced every spinner in the app
- Installer fixes: Desktop and Start Menu shortcuts are created reliably on Windows

---v7.9.3
# The orbit begins
- Single-digit version bump policy introduced: 7.9.9 advances to 8.0.0, never a double-digit jump
- Release pipeline attaches every artifact automatically after each version bump

---v7.8.13
# Maintenance
- The Windows MSI is built again alongside the portable ZIP
- Smoke evidence is kept out of release assets

---v7.8.6
# First desktop release across Windows, macOS and Linux
- Windows installer (MSI) and portable ZIP, macOS DMG, Linux DEB, RPM and AppImage
- Desktop and Start Menu shortcuts on Windows
- Kotlin Multiplatform + Compose codebase shared with Muzik for Android

---v7.8.5
# Hello, world
