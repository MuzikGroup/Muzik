# Translation attribution

Muzik's shared translations live in `shared/src/commonMain/composeResources/values-*/strings.xml`
and are maintained through the Muzik translation project.

Muzik is built by Ignatius (lead developer) together with the Pipo Team contributors,
and every translation is distributed under the project's GPL-3.0 license.

See [strings.md](strings.md) for the catalog workflow.
