# Changelog

---v7.9.4

## What's New

- Brand-new loading experience: every spinner is now the Muzik "M" logo travelling in a circular motion — on the player song/video buttons, menus, dialogs and every loading screen
- Seamless desktop install: the Windows installer now creates a Desktop shortcut and a Start Menu entry, and Linux packages register the app in the applications menu

## Improvements

- Version numbers stay single-digit on every component (7.9.9 rolls to 8.0.0, never 7.9.10)
- README badges and one-click APK links always track the latest GitHub release automatically

---v7.8.4

## What's New

- Universal device support: Muzik now ships with all CPU architectures bundled (arm64-v8a, armeabi-v7a, x86, x86_64), so it installs and runs on every Android device — phones, tablets, foldables, ChromeOS laptops, and emulators
- In-app support button now points to Buy Me a Soda
- Sponsor button added to GitHub — support the project in one click

## Improvements

- Automated version bumping: every push to main increments the build version by 0.0.1 and publishes a fresh release automatically
- One-click APK installation directly from the README
